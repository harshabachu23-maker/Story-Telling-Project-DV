STUDENT ACADEMIC PERFORMANCE STORYTELLING WEBSITE

How to use:
1. Download and unzip this folder.
2. Open index.html in Chrome or another browser.
3. The dashboard works as a self-contained website; charts and filters run in the browser.

To publish online:
Upload index.html to a GitHub repository and enable GitHub Pages, or use another static website host.

Data note:
The site generates illustrative synthetic student data in the browser. It is not actual college data.
